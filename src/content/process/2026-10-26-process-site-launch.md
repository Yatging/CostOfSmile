Following supervisor feedback, the project gained a dedicated process website.

The archive separates Process, Material Archive, Research, Experiments and Supervisor Feedback so that development remains visible rather than presenting only a final artwork.

A browser-based Pages CMS publishing workflow was also prepared so that future entries can be added without manually editing GitHub files.
